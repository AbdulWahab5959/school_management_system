# School Management System

## 1. Introduction
### 1.1 Purpose
The purpose of this document is to define the complete requirements for the School Management
System (SMS), providing a centralized platform for managing academic, administrative, and
student-related activities efficiently.
### 1.2 Scope
The system will automate daily operations like student information, attendance, grading, staff
management and financial records. The system will also provide role-based access for different
stakeholders: students, teachers, administrators, and parents.
## 2. System Features
### 2.1 User Management
#### 2.1.1 Administrator
- Create/Manage users: Admin can create students, teachers and staff.
#### 2.1.2 Students
- Profile Management: Students can view and update their profiles.
- View Grades & Attendance: Students can check their grades and attendance records.
#### 2.1.3 Teachers
- Manage Attendance: Mark and track student attendance.
- Manage Grades: Upload grades for exams, assignments, and projects.
### 2.2 Academic Management
#### 2.2.1 Class Management
- Class Scheduling: Set up and manage classes for different grades and sections.
- Subject Management: Manage subjects for each grade with assigned teachers.
#### 2.2.2 Attendance Management
- Student Attendance: Teachers can mark student attendance manually.
- Attendance Reports: Generate attendance reports based on daily, weekly, or monthly
attendance.
#### 2.2.3 Grading System
- Manage Grades: Input grades for assignments, quizzes, and exams.
- Report Cards: Generate automated report cards for students with grading information.
### 2.4 Fee and Financial Management
#### 2.4.1 Fee Structure Management
- Fee Types: Set up fee structures based on classes, subjects, and other criteria (tuition,
transport, exam fees).
#### 2.4.2 Fee Payment and Tracking
- Invoice Generation: Automatically generate fee invoices for each student.
- Payment Tracking: Track and record payments, with the ability to send overdue reminders.
- Fee Reports: Generate fee collection reports for administrators.
## 2.8 Report Generation
- Custom Reports: Generate various reports like attendance, grades, fee collection, and more.
- Export Options: Export reports in PDF, CSV, or Excel formats.
- Automated Reports: Schedule automated report generation for stakeholders.
